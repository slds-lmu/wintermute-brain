## 9. Avoid

Numeric confidence scores · forgetting/decay curves · LLM-resolved
merges · `log.md` with many writers · auto-commit per tool call ·
query-time tier filtering · Basic Memory as the base (it writes into
every file; AGPL) · GraphRAG/LightRAG (expensive, redundant) · hosted
Jina Reader · trufflehog verification mode (it sends candidate secrets
out to verify them).
