# Wiki spec decisions: minimal page types, lock and commit checks, two-layer lint

- **Page types (P5), owner's decision:** Types exist only where membership can't be disputed: `person`, `meeting`, `paper`, `grant`, `source`. Everything else is an untyped `page`, and projects and courses become tags. The owner rejected a `synthesis` type, so saved answers become plain pages. Reason: the owner wants no ontology that grows into team debates.
- **Human corrections (P7), owner's decision:** A `locked: true` field on a page is the emergency brake. Agent commits go through `tools/commit-op`, which rejects commits that touch locked pages or overwrite lines last written by a human. The exception is a commit message naming a newer source (`Overrides-human:`). The same checks also run as a required GitHub check before anything lands on `main`, because local hooks can be skipped. The owner asked for the pre-merge check. The `audit/` inbox is parked as K18.
- **Lint (P8), two layers:** Mechanical checks run on every push. AI judgment checks (stale claims, duplicates, uncited claims, sentence-to-source mismatch) run by hand in the MVP and only report, never fix. The owner decided against IWE and asked for our own validator, with a note to revisit IWE if that script starts duplicating it (K19).
- **Search (N2), owner's decision:** qmd from the MVP on, with grep kept as a fallback so the wiki never depends on qmd.
- **Batch 1, concurrency, accepted:** one branch or worktree per operation, no AI conflict resolution, search before every page creation, one git identity per agent, one commit per operation. Rejected: merge drivers for append files, and humans-only promotion out of `draft`. Parked: slug reservation (K20), role-partitioned writes (K21), single-writer for helper agents (K22).
- **Batch 2, ingest, accepted:** classify each source before writing, copy numbers and quotes exactly from the source, write nothing if the source adds nothing, one source at a time, actively search for counter-evidence, store changed sources as new raw revisions. MVP channels: web pages (defuddle), arXiv LaTeX, paper downloads via the in-house tool, other PDFs via MinerU or Marker after a 10-paper test; secret scanning before raw writes. Mattermost, sessions, mail, Google Docs, meetings and the personal-data filter are deferred. Parked: two-source rule for risky claims (K23) and the retract operation (K24).
- **Batches 3–4, lint and query, accepted:** three levels of lint action (fix trivial, report mechanical, report judgment), a false-alarm goal of about 15%, tests with a sample wiki, query order index, then folder index, then search, then top pages. Per-folder `CLAUDE.md` files instead of pasting the index, and a gitignore line for the Smart Connections cache. Parked: contradiction hunting (K25), the unanswered-questions log (K26).
- **Open, priority (K17):** Workflow for resolving visible disputes. Still open: who gets notified, how a human resolves a dispute, whether an agent may propose a resolution, how the resolution is recorded, and a lint report for old disputes.
- **Pending:** Batch 5 (F1–F5, M1, M10, M11, M16, M18, slug patterns) is proposed but not yet approved. The owner must also talk to the `slds-setup-memory` authors (F4).
