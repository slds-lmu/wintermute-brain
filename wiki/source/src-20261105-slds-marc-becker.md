## Summary

The profile page of Marc Becker on the website of the Statistical Learning and Data
Science Chair at LMU Munich. It lists a contact address at the Institut
für Statistik, research interests, links to GitHub, Google Scholar
and ORCID profiles, selected software and a publication list
[Marc Becker (SLDS profile page)](/wiki/source/src-20261105-slds-marc-becker.md).

## Key points

- **Research interests:** black-box optimization, machine learning,
  hyperparameter tuning, geostatistics, remote sensing
  [Marc Becker (SLDS profile page)](/wiki/source/src-20261105-slds-marc-becker.md).
- **Software (selection):** `mlr3`, `bbotk`, `mlr3tuning`, `mlr3fselect`,
  `mlr3hyperband`
  [Marc Becker (SLDS profile page)](/wiki/source/src-20261105-slds-marc-becker.md).
- **Publications** include the `mlr3mbo` paper in *Patterns* 7, 101614
  (2026), `rush` for asynchronous distributed computing in R (2026), and
  four chapters of the book *Applied machine learning using mlr3 in R*
  (2024)
  [Marc Becker (SLDS profile page)](/wiki/source/src-20261105-slds-marc-becker.md).
