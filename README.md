# brain-group — the SLDS brain

An LLM-maintained group wiki: immutable raw sources in `raw/`, agent-written
Markdown pages in `wiki/`, git as the log and the provenance. Agents (Claude
Code sessions, a server-side compile worker) do the filing, linking and
summarising; humans read, ask, correct and steer. Design: `specs/`.

```
CLAUDE.md          schema for agents working in this repo
raw/               immutable sources: raw/<channel>/<YYYY>/<id>/ + source.yaml
wiki/<type>/       person, meeting, paper, grant, source, page
templates/         one template per typed page
index.md, wiki/*/index.md   generated by tools/index (never hand-edited)
tools/             index, lint, check_evidence, start-op, commit-op, log, report-health
plugin/            Claude Code plugin: /brain-ingest, /brain-ask, /brain-edit, /brain-lint, session hooks
server/            compile worker, qmd auth proxy, GitHub App token, systemd units
.github/workflows/ required check (lint + preconditions) and index regeneration
specs/             the design (00–06), prior art, parked ideas
```

## Use it

- **Read:** browse on GitHub, or open the clone as an Obsidian vault
  (Settings → Files and links: turn off Wikilinks, link format "Absolute
  path in vault"). Links are root-absolute (`/wiki/page/x.md`).
- **Ask / ingest / edit / lint:** install the `brain` plugin
  (`plugin/README.md`) and use the commands in any Claude Code session.
- **Edit by hand:** normal git. Humans may edit anything; set `locked: true`
  in a page's frontmatter to keep agents off it.

## Tools

All stdlib Python 3.10+ plus PyYAML. Run from anywhere inside the repo.

```bash
tools/index                 # regenerate all index files (--check to verify)
tools/lint [--fix] [--base REV] [--agent NAME]   # mechanical lint (03 § 5.1)
tools/check_evidence [pages]   # grounding: literals vs. cited raw files (--queue: compile backlog)
tools/start-op --agent NAME    # fresh worktree for one operation
tools/commit-op …              # the agents' only write path: lint, preconditions, PR with auto-merge
tools/log [--op ingest]        # readable digest of the git log
python3 -m unittest discover -s tools/tests   # fixture wiki + one broken copy per rule
```

## GitHub setup

1. Branch protection on `main`: require the `check` workflow, no
   force-push, no deletion, rebase merge enabled, auto-merge enabled.
2. Secret `BRAIN_APP_TOKEN` (or allow the `index` workflow to push) so
   `index.yml` can commit regenerated indexes to `main`.
3. Git LFS enabled; members clone with `GIT_LFS_SKIP_SMUDGE=1`.
4. The standing issue "Brain health" is created on first use by
   `tools/report-health`.
